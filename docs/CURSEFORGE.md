# Ichorworks: Thaumic Tinkerer

**Ichorworks is an independent, non-commercial beta port of Thaumic Tinkerer 1.7.10, including KAMI, for Thaumaturge.** It is not an official release and is not endorsed by the original authors. This project is separate from other unofficial ports.

Rediscover Thaumic Tinker's machines, wands and late-game Ichor equipment alongside Thaumaturge's research and magic systems:

- Make tools and devices such as the Thaumic Restorer, Essentia Funnel, magnets, Transvector devices and Osmotic Enchanter.
- Craft classic wand foci for smelting, healing, movement, teleportation and more, integrated with Thaumaturge's modular spell system.
- Explore elemental fire, infused crops, soul aspects and custom enchantments.
- Progress into KAMI's Ichor materials, armour, tools, gateway and bedrock mining dimension.

The older user interfaces and some mechanics have been adapted to modern Minecraft. Several original visual effects and integrations remain incomplete; see [porting notes](https://github.com/lingmu0/thaumic-tinkerer-thaumaturge/blob/main/docs/PORTING.md) in the source repository.

## Requirements

Install the file matching your Minecraft version and its separately distributed dependencies on both client and server:

- Minecraft 1.21.1 or 26.1.2 with a matching version of NeoForge.
- [Thaumaturge 1.1.0](https://www.curseforge.com/minecraft/mc-mods/thaumaturge/files/all), plus its required dependencies.
- [Curios API](https://www.curseforge.com/minecraft/mc-mods/curios).

The current build is **beta**: it has been compiled and checked offline, but has not been verified in a running client or dedicated server. Back up worlds before testing. Older Thaumaturge versions and later releases have not been verified with this build.
