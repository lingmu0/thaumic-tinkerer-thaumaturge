## 主要交互

- 研究位于 Thaumonomicon 的“神秘工匠”分类，需先解锁前置的炼器分类。KAMI 起点要求完成共同前置基础研究及本附属非 KAMI 研究，排除自己的后继以避免循环。
- 经验、净化护符装备在 Curios 项链栏，潜行使用切换开关；猫护符为项链，无底袋为腰带，黑洞护符为戒指。
- 十种核心装在 Thaumaturge 法杖上使用，相应节点也出现在核心操纵台中，受研究条件限制。召回需要至少三秒蓄力。
- 无底袋保留 117 格，以 54 + 54 + 9 三页原版箱子界面呈现；潜行使用切换页。禁止放入自身等容器物品。
- KAMI 装备潜行使用切换效果，高级工具保留模式切换及对应物品图标；不依赖旧版 U 键。
- 机器使用手持物右键/潜行右键控制，具体操作在各研究页面中。绑定器先记录目标，再点击设备绑定；有效范围和同维度条件会校验。
- 传送网关保存最多十个珍珠目的地，支持选择、传送和拆除回收珍珠；同维度验证及到达锁定保留。

## 有意的现代适配

旧版每种基础要素 Vis 的奥术合成，转换成现代工作台总 Vis 和所需基础要素各一个水晶；注魔保留原要素数量与不稳定度。消失的要素合并到前置现有要素，例如 Pannus → Fabrico、Sano → Victus、Telum → Aversio、Tutamen → Praemunio、Iter → Motus、Lucrum/Fames → Desiderium。合并时数量相加。

旧核心依赖物改用适当等级的 Thaumaturge 空白核心，旧碎片对应基础水晶。旧元数据物品改成具名注册 ID。原有可选知识共享配方默认启用。灵魂系统保留原来十六种身份及三级含义，现代要素合并不会合并灵魂身份。

基岩维度保留 256 高基岩体、按柱选矿和每柱 200 次矿脉尝试，旧 Ore Dictionary 改为已安装的 `c:ores/<材料>` 标签，旧矿脉生成器改为有界随机游走。机车采用单绑定中继代替旧双中继轨道拓扑。机器移动和方块搬移保留容器数据，并触发 NeoForge 破坏/放置事件；这仍需在实际保护模组环境验证。

## 明确差异与未验证部分

- 未复刻旧版翅膀动画、放置镜的预览残影及网关特殊模型；装备使用原材质和原护甲值，机器使用静态方块模型。
- 旧版专用 GUI 多处改为原版容器或右键操作。旧版客户端粒子、光束和工具动画采用现代粒子/静态渲染。
- 尚无旧 ComputerCraft/OpenComputers 外设及旧 Thaumcraft 傀儡标记/装饰 API 联动；傀儡连接器提供现代前置拥有者、归位、导航和状态控制。
- 现代核心引擎采用脉冲/蓄力调度，Vis 折扣、伤害和时序不保证逐 tick 与 1.7.10 相同。
- 未启动游戏；多人数容器同步、世界生成、实际研究解锁、法杖施法、机器交互及与其他模组联动仍需客户端/专用服务器实测。

因此本交付标记为开发版，不能称为经过实测的完整等价复刻。旧存档数据不兼容 1.7.10，不提供存档迁移。
